MDI without the tab strip — dock, window menu, peek & split

Click a module in the sidebar. Each one opens as its own page kept alive in the DOM — like MDI child windows — but with no top strip and no permanent dock: switching happens in the topbar Window menu or by re-clicking a sidebar module. Standalone file; just open it in a browser.

  • Open a module — the button in the topbar opens the Window menu (checkmark = active, badges = pending counts, × = close); re-clicking the sidebar module just focuses its open page.
  • Want the dock back? The button shows open pages as cards at the bottom — hidden by default for a cleaner look, choice remembered.
  • Students, Counseling, Discipline — click any row: a peek panel slides in from the right without leaving the list. Dismiss with Esc, ×, or a click outside.
  • Pin the peek () — it docks beside the list as a split view; while docked, clicking other rows reuses the pane. Unpin returns it to the overlay.
  • State survives switching — type in the Students search, scroll, switch modules, come back: everything is exactly where you left it.
  • Refresh the page — your open set of pages is restored from localStorage (session restore).
  • Keep opening modules — at 8 pages the oldest closes automatically with a toast (memory bound). Close any page with × or middle-click; reopening re-fetches like a normal PJAX load.

In the real system this is the same per-page engine as the reverted tab patch inside public/js/pjax.js — only the switcher and panel presentation change. No top strip anywhere.
